# Tech English Trainer

אני רוצה שתבנה לי אפליקציה ללימוד אנגלית טכנית + שאלות ותשובות בתחום בדיקות תוכנה + שאלות ותשובות בתחום תוכנה
אני אעביר לך מסמכים שעל פיהם פחות או יותר תהיה בנויה הפליקציה , כמובן שתוכל להוסיף דברים משלך ולייעץ אולי מה לעשות אחרת
בקטע של האנגלית טכנית אני מתכוון שתהיה מילה באנגלית ומתחתיה הפירוש בעברית
אני רוצה שזה יהיה מחולק לסטים :
כל סט יכיל 10 מילים 
כל סט ידורג לפי מספרים
סט מספר 1 - יכיל מילים קלות  / מוכרות / בסיסיות
וכככל שנעלה במספר הסט המילים יהיו בדרגות קושי גבוהות יותר
בכניסה לאפליקציה במסך הראשי יופיעו 3 אפשרויות:
"תרגול מילים באנגלית טכנית"
"תרגול שאלות ותשובות ב QA"
"תרגול שאלות ותשובות בתוכנה"

בכניסה לסט מסוים תופיע המילה באנגלית ומתחתיה הפירוש בעברית למשך 5 שניות ואז נעבור למילה הבא בסט שוב למשך 5 שניות וכך הלאה 
כמובן שבזמן הצגת המילים האפליקציה תגיד את המילה באנגלית
זה בעצם מה שנקרא "שטיפת מוח" כך קל יותר לשנן את המילים.
בנוסף תיצור כפתור לעצירה כדי שבמידה והמשתמש ירצה להתעקב על מילה שהוא לא בטוח בה יוכל להתמקד בה ולא לחכות לפעם הבא שהיא תופיע
בנוסף לכפתור העצירה תיצור כפתור להשמעה חוזרת של המילה באנגלית
